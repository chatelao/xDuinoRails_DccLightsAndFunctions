# Contributing to xDuinoRails_DccLightsAndFunctions

Thank you for your interest in contributing to this project! We welcome contributions from the community to make this library better for everyone.

## How to Contribute

1.  **Fork the Repository:** Create a fork of this repository on GitHub.
2.  **Create a Branch:** Create a new branch for your feature or bug fix.
    ```bash
    git checkout -b my-new-feature
    ```
3.  **Make Changes:** Implement your changes, adhering to the coding style (see `.clang-format`).
4.  **Test Your Changes:** Verify that your changes work as expected. If adding new features, please add relevant examples or tests.
5.  **Submit a Pull Request:** Push your changes to your fork and submit a pull request to the main repository.

## Coding Standards

*   We use a modified Google C++ Style with 4-space indentation.
*   Please ensure your code compiles without warnings.
*   Document public API methods using Doxygen-style comments.

## Reporting Issues

If you encounter any bugs or have feature requests, please open an issue on the GitHub repository. Provide as much detail as possible, including steps to reproduce the issue.
